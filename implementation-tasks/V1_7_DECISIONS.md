# V1.7 决策记录（MD 课件编辑与题库 AI 选题生成）

产品负责人于 2026-09-02 至 2026-09-03 会话中逐项确认。设计基准：`docs/v1.7-md-editing-and-bank-integration-plan.md`。

## D27 · 所有 md 文件可 AI 二次编辑

- 产品负责人原话："按理说所有的 md 文件应该都是可以用 ai 进行二次编辑的吧。不一定必须是通过 ai 生成的才能改吧"（2026-09-02 验收 V1.6 时提出，随即将 V1.6 的 D23 收口标记为 V1.7 中放宽）。
- 修改对象 = 任意 `text/markdown` 的 managed 文件（含外部导入 md）；office/pdf/图片维持不可作 AI 修改对象（文本不可靠进出上下文）。
- AI 修改产物按版本语义保存（V1.5.2 工作副本 + 版本链零变化），绝不覆盖原件。

## D28 · md 人工直接编辑（含公式、插图、排版）

- 2026-09-02 列为候选，2026-09-03 升格为必做："md 人工编辑这个最好也在这一轮实现"。
- 立项要求（2026-09-03 原话）："MD 编辑里要必要能实现输入行级公式的。还有插入图片，修改字体大小等基础的 md 编辑功能的"。
- 实现：阅读器编辑/预览切换 + 工具栏（零新依赖，受控 textarea + 分屏 KaTeX 预览）；行级公式 = `$…$` 原文输入 + LaTeX 片段速查模板；插图 = 本课文件引用插入（不做 base64）；"字号"以 md 标题层级/上下标模板实现（不引入 HTML 内联样式——渲染端安全边界不放松）。

## D29 · 编辑保存语义：存为新版本（推荐项，立项默认）

- 存为新版本：版本链文件 → ` · 第 N+1 版.md`；外部导入 md → `原名（编辑版）.md` 副本；旧版永不丢失。
- 不提供"直接改当前版"：会打破版本不可变与"不覆盖老师原资料"两条既有边界；如产品负责人后续坚持要，须专门复议。
- 外部根目录资料不可直接编辑，须先复制到本课成 managed 副本（原件永远只读）。

## D30 · 题库 AI 自动选题（两阶段生成）

- 产品负责人最终目标（2026-09-03 原话）："和 ai 描述之后，你只要选上了参考我们的题库，就你通过和 ai 对话，ai 自动会去参考相对应的 tag 的题目，然后从中选择合适的题目。我们的题库的题目都是有年级、难度、tag 的"——**不是**老师手动挑题。
- 两阶段：AI 出结构化检索计划（JSON 一一映射 QuestionBankSearchRequest）→ Main 本地确定性执行（复用 QuestionBankService.search）→ 候选全文进第二阶段，AI 选题写作（不得杜撰）。
- 否决 function-calling 工具循环（与流式面板/取消/静默超时交织复杂、难测试）；否决手动挑题注入（不是产品目标）。
- 定位（产品负责人 2026-09-03 确认）："产品上一体（题库成为 AI 生成的知识源），架构上解耦（独立库、窄接口、可缺省）"；题库未安装时开关置灰引导导入，生成体验与现状一致。
- 过目步保留：检索计划 + 候选清单在方案确认卡展示，支持自然语言调整重检索与逐题剔除；确认后进入既有流式生成。
- ID 稳定性（2026-09-03 代码核实）：导出器强制稳定 `source_uid`（主键 + source_question_id UNIQUE），一题一 ID 自第一天保证；题目进课件即文本固化，无运行时引用；`content_hash` 已存在，供未来沉淀侧检测同 ID 不同内容。
- 含图题目：候选标注"含图"但不进上下文（DeepSeek 无 vision）；不做 vision 直读（V1.6 D26 遗留结论沿用）。

## D31 · 学生版 / 教师版双输出

- 产品负责人裁决（2026-09-03）："对于这个问题（题库参与感标注），其实完全可以出一份学生版，一份教师版的"。
- 教师版：含 [选自题库：tag/难度] 标注 + 答案解析集中区块；学生版：纯题面无标注无答案，可直接印发。
- 实现：教师版为主生成，学生版第二次快速生成（prompt = 基于教师版剥离答案/标注）；否决本地规则剥离（要求生成格式刚性区块，约束 AI 输出自由度）。
- 发布命名：`讲义 · 第 N 版.md` 与 `讲义 · 第 N 版 · 学生版.md`；真实自测费用预估 ≤ ¥3（双版约 1.5–2 倍单版成本）。
