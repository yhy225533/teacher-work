## 4. 冒烟期发现并修复的缺陷

**课程页文件计数 chips 停更**（V19-C 验收范围，V19-F 冒烟发现）：外部资料 `importToLesson` 只 `enqueueIndex` 不发 `notifyContentChanged`，老师停在课程页导入外部资料时讲义/材料计数不刷新（停在 0）。修复（`src/renderer/course-detail.tsx`）：计数跟随两条线——既有 `files.onContentChanged`（编辑/发布）+ core overview 结构变化（`overviewRevision = nodes + lessonSessions 数量`）触发兜底重拉一次 `files.getOverview`。钉测：`tests/v1.9-course-hero-card.test.ts` 新增「双线计数跟随」结构钉测（8 例全过）。**不属 IPC/迁移变更**：external-library-ipc 的 copyToLesson/importToLesson 行为保持 V1.7 冻结语义不动。

## 5. 自动化边界（已知限制，如实记录）

1. **原生保存对话框**：`dialog.showSaveDialog` 为 Windows 模态，无法无人值守驱动（不进 DevTools/CDP）。保存路径（另存为/取消 `saved:false`/目标占用/超时清理/打印窗销毁/并发 BUSY）已由 export-service / export-ipc 注入测试全覆盖（fake 窗口端口 + fake printToPDF，20 例）；**产品负责人人工走查**覆盖真实保存路径（§6 导出清单）。
2. **CDP Page.printToPDF**：本应用 Electron 的调试协议未实现该方法（page-session 与浏览器级 flat-session 实测均 -32601 wasn't found）；真实产物通道是 Main `webContents.printToPDF`（ExportService.printToPdfOptions 同参编排，注入测试已钉 A4/页边距/页眉页脚模板/转义），字节级保真归入人工走查（§6 导出清单 1–4）。
3. **错误码跨 contextBridge 不存活**：Electron 将 IPC 抛回的 Error 重建为普通 Error，自定义 `code` 字段不存活（既有行为，V1.7 起全部 UI 错误分支只消费 `message`——本冒烟实测确认 message 完整存活，UI 呈现不受影响；`App.tsx` workspace.getInfo 的 code 分支为不触发的兜底）。

## 6. 安全边界复核（V19-F 门禁项）

- **sender 校验**：`export:get-print-payload` / `export:print-ready` 仅接受当前隐藏打印窗（webContents.id 比对），冒充/识别失败均拒绝——注入测试 3 例 + 冒烟端到端 1 例；
- **原子落盘**：`export:print-to-pdf` 产物经临时文件 + 原子重命名，失败清理临时文件；`files:write-version` D29 语义零变化；
- **路径不回传**：`ExportPrintResult` 守卫 hasOnlyKeys(['saved'])——保存路径绝不进响应（V11-01 合同）；默认名 `原名.md → 原名.pdf`（stripMarkdownExtension）；
- **日志无正文**：export IPC 日志只记 channel + 错误码；Main 二次校验防 Renderer 伪造 fileId/lessonId（非 md / 未挂课 / 超大 body 均稳定拒绝）；
- **PDF 不入库**：产物不登记 files 表、不进索引/备份（导出链路零 SQLite 写，export-service 全走 readText 只读 + 文件系统落盘）；
- **零迁移/零新依赖**：migration 无 v19；package.json 零变化；UI 节点零新 IPC。
