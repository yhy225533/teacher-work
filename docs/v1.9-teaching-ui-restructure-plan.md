## 1. 背景与目标

2026-09-07 三轮界面评审确认的三个病灶：

1. **备课工作台（draft-panel）**：主列竖排 5-6 个功能区，一次改讲义竖穿 4 张卡；"参考题库"开关与候选隔两张卡；成果卡 7 键平权；成果阅读区被挤到底部；生成时流式卡插入导致页面跳动；模式行独占一行。
2. **课件区**：三层头部（页面头 + 本课课件头 + 可读资料头）+ 11 个平铺按钮（加"导出 PDF"则 12）；课次标题同屏重复 3 次；核心信息只有文件名+大小一行小字。
3. **课程页**：右上方是静态课程名片（课程名/模式/学生名，一周才变一次），"当前：第 12 课"只是 12px 小字；行动入口在约 200px 之下的 Viewed Lesson 卡。
4. **编辑体验不一致**：课件区用 MdEditor（分屏+KaTeX 预览+公式引擎+热保存，V1.7.3 打磨），备课工作台编辑 AI 成果却是裸 textarea（rows=24，无预览）——同一应用两套 md 编辑体验。

目标：以"纯 renderer + CSS 重构 + 组件复用"消除以上四项，生成/题库/发布/版本链/反馈逻辑零改动。

产品负责人关键裁决（2026-09-07 原话）："右边这个配置应该是指我和 AI 进行对话……但凡有东西，本质都是 AI 修改，哪怕完全不行，你也会跟 AI 说这个东西完全不行，我们要整个进行重做。""修改记录……要么不放在这，要么可以收回去隐藏。""不是所有的备课都是同一种工作流，我们没有办法去判断这个工作流一定是这样的。"

## 3. 方案 A · 备课工作台对话式重做（V19-A）

### 3.1 布局

```
页面头：kicker「AI 修改」+ 课次标题（用户已认可的短样式）
        右侧：[🕘 修改记录 N]（浮层按钮）+ [退出修改，回到课件]
主区 grid：主舞台 minmax(0,1fr) ｜ 对话栏 302px（<1100px 堆叠，对话栏折叠为摘要条）
```

### 3.2 对话栏（右）

- **依据区**（"AI 能看到的"）：
  - 「这次改什么」radio 两项：`这份讲义`（默认，自动挂当前讲义 chip，带"自动"徽标）｜`整个课件包`（lesson 基线，标注 N 份当前版课件）；无 md 课次时整区切换为"从零生成"引导 + 外部/素材库两张添加卡（沿用 prep-add-card）；
  - 参考文件 chips（✕ 移除）+ ＋ 本课资料/外部资料/素材库；
  - 参考题库开关行（目标题数 + 学生版开关，沿用 PrepBankOptions）；
- **对 AI 说**：textarea（= requirement，`DRAFT_REQUIREMENT_MAX_CHARS` 上限不变，行数加大到 5 行）；底部 Skill select + `✦ 发送`；生成中禁用；
- 预算：撤"已用 N 字"长文案行，改为依据区底部一行小字 + 超预算红态提示（D25 确认弹窗逻辑不动）。

**模式收敛（合同零改动）**：`prepMode` 与 `draft:generate` 载荷的 `mode` 字段保留；UI 撤除顶部模式行——进入页面按课次状态自动初始化（有 md → single + 当前讲义；无 → new），「整个课件包」选项即 lesson。"整课重做"不再是独立按钮，是要求里的一句话 + 范围选项。

### 3.3 主舞台（左，固定位置、同卡替换、无步骤编号）

- **方案态**（improvePhase==='review'）：标题"修改方案（确认后生成）" + 方案正文 + （题库开时）候选列表就地渲染（逐题剔除/调整重选，行内）+ 底部行 `✓ 确认并生成`（primary）/`让 AI 调整`（= 重新出方案，取对话栏最新要求）/`放弃`；
- **生成态**：同位置换流式正文（思考行：已思考 N 字 · M 秒 + 逐字正文 + 取消）——不插入新卡、页面不跳（V1.6 流式通道零改动）；
- **成果态**：标题 + `未发布/已确认` 徽标 + 正文大阅读区 + 三主键 `✎ 编辑`｜`⇄ 新旧对比`（有基线时）｜`⬆ 保存为新版本`（primary）+ `⋯`（重新生成 / 保存到本次课次 / 查看课件 / 删除草稿[红，底部]）；保存/发布/删除的现行 IPC 与 draft_status 生命周期零改动；
- **对比态**：同卡左右分栏（旧基线 ｜ 新副本）；
- **空态**：分状态引导（从零生成 / 尚无方案）；
- 恢复提示（未发布工作副本）保留为舞台顶部 inline 通知。

### 3.4 修改记录浮层

- 默认收起（0 占版面）；顶部 `🕘 修改记录 N` 点击展开浮层（视觉复用 TeachingContentDrawer 模式）；
- 条目 = 现 rail 行内容（节点名/时间/教师版·学生版徽标/修改中·已确认/删除草稿）；选择即加载到主舞台并关闭浮层；
- 全局"修改记录"分区（DraftPanel context=null 的草稿箱用法）不动；发布/生成成功的即时 inline 提示不动。

### 3.5 成果编辑复用 MdEditor（D56）

- `MdEditor` 新增受控用法：可选 `initialBody` + `onSaveBody(bodyMd)`（缺省 = 现行文件用法，D29 语义零变化，课件区调用零改动）；
- 成果态 `✎ 编辑` 渲染 MdEditor：initialBody = note.bodyMd，保存触发现行 `saveModification`（note 语义），热保存键按 `md-editor-draft:note:<noteId>` 隔离命名空间；取消 = 丢弃编辑；
- 两处编辑体验统一（三视图/分屏 KaTeX/公式引擎/斜杠菜单/撤销重做/热保存全套）。

### 3.6 撤除项

- prep-mode-bar（模式行）；固定工作流步骤链/阶段编号（主区标题只陈述"现在是什么"）；独立题库候选卡与独立确认条（并入方案态）；预算长文案行。

## 4. 方案 B · 课件区双头合并与操作收纳（V19-B）

- **合并工具行**（lesson-files-section 头 + 阅读器头合一）：
  - 左：课次标题（periodTitle · lesson.title）+ 当前文件信息胶囊（文件名 · 当前徽标 · 大小 · 来源标签 `lessonFileSourceLabel`）；
  - 右：`✦ 修改这份`（进入 AI 修改，自动挂该文件）｜`✎ 编辑`（md 时，MdEditor）｜`⬇ 导出 PDF`（V19-E 接线后才渲染）｜`沉浸阅读`｜`⋯`；
- **⋯ 菜单**（三处共用的菜单组件在本节点落地）：分组"本课"（刷新 / 继续上次修改 / 整个课件包重做[lesson 范围]）、"本文件"（设为讲义底稿 / 系统打开 / 所在文件夹 / 增强解析(MinerU) / —分隔— 从本课移除[红，底部]）；危险项在菜单底部红区，既有二次确认弹窗不动；
- 无 md 新课次：保留"AI 新建备课/继续上次备课"主键引导；只读课次（已结束）：仅 `⬇ 导出 PDF`（E 后）+ ⋯（系统打开/所在文件夹）；
- 正文区去第二头（"可读资料"块退役，信息并入胶囊）；阅读/编辑/题图跟随/MinerU/提讲义/移除语义与 V1.8.1 分组树、历史版本折叠全部不动；draft-panel 内共享的 ScopeFileList 等组件不在本节点触碰。

## 5. 方案 C · 课程页当前课次行动头（V19-C）

- **撤** `course-page-header` 统计条（全部课程 N/修改记录 N/刷新/仅创建课程/+ 快速建课 → 收进行动卡 ⋯ 的"全局"组）；未选课程的空态保留最小页头（刷新 + 建课）；
- **course-detail 头 → 当前课次行动卡**：
  - 小字 crumb：课程名 · 一对一/班课 · 阶段 · 共 N 课（第 M 课）；
  - 大字：当前课次标题 + Current/已结束徽标；
  - chips：🕘 排课时间（session.scheduledAt 本地格式）｜👤 学生名（一对一）/在读 N 人（班课）｜📘 讲义 N ｜📎 材料 N（`splitLessonFilesByRole` 计数）｜上节反馈 ✓（`lessonFeedbackStatus`）；
  - 行动键：`▶ 进入教学内容`（primary）｜`点名`｜`确认本课已上`；`⋯`（本课：调整当前课次/设置时间；本课程：学生名单[切学生 tab]/修改记录/结束课程；全局：+ 快速建课/+ 仅创建课程/刷新）；
- **Viewed 规则**：选中非当前课次时，行动卡主角换为该课次（chips/行动键指向它；"进入教学内容"定位该课次）；已结束课程行动键仅"查看教学内容"+ ⋯（重新开启）；
- 今日待点名条、课程列表、课次表、点名弹窗、确认已上弹窗（V1.8）全部不动；chips 数据全部来自现有 overview 派生，零新增 IPC。
