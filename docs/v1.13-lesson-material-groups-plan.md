## 1. 目标与非目标

目标：

1. 课件区挂课文件按教学角色分为四组展示：📘 讲义 / ✏️ 习题与作业 / 📄 试卷与复习 / 📎 其他资料；
2. 分组 = 手动覆盖（持久化，新列）优先，未覆盖文件按冻结启发式自动归组；
3. 老师可在课件区对单个文件手动改组（含"恢复自动"）；
4. 课程页行动卡讲义/材料计数随新分组语义更新（讲义 = lecture 组）。

非目标（本次不做）：

- 学生资料（student_files）分组——学生页无分组需求，后续候选；
- 学生版/教师版第二维度标签（同组内角标）——后续候选；
- 导入脚本改造（反馈 md 不入库等）——脚本是一次性工具，规则改进记录在本方案 §6 供下次导入前执行；
- MD 正文本地链接可点击打开——V1.13 候选未立项，不动渲染链；
- AI 修改/讲义底稿/导出/反馈/题库链任何语义变化。

## 2. 数据与合同（D74）

### 2.1 migration v18：`lesson_files.role` 列

```sql
ALTER TABLE lesson_files ADD COLUMN role TEXT
  CHECK (role IS NULL OR role IN ('lecture', 'exercise', 'exam', 'misc'));
```

- 纯 ADD COLUMN，**无表重建**（v16 事故守卫框架照用，但本迁移不触发该风险面）；FK/CASCADE/PK 不变；
- 语义 = **手动覆盖组**：NULL = 自动（渲染端按 D75 启发式实时归组）；非 NULL = 老师手动指定；
- **不回填启发式结果**：启发式随版本可改进，NULL 行永远吃到最新规则；只有老师的手动决定才落库；
- 新增挂课路径（importToLesson/copyAndRegister/外部 copy-to-lesson/pilot 脚本）零改动——新行 role 为 NULL，自动归组。

### 2.2 合同扩展（`src/shared/file-contracts.ts`）

```ts
export type LessonMaterialGroup = 'lecture' | 'exercise' | 'exam' | 'misc'

export interface SetLessonMaterialGroupRequest {
  readonly fileId: string
  readonly group: LessonMaterialGroup | null   // null = 恢复自动
}

export interface SetLessonMaterialGroupResult {
  readonly file: ManagedFileRecord
  readonly group: LessonMaterialGroup | null
}
```

- `ManagedFileLink` 增加可选 `role?: LessonMaterialGroup | null`（仅 lesson 链接由 Main 填写；student 链接恒缺省）；守卫演进放行该可选键；
- 新通道 `files:set-material-group`（`FILE_IPC_CHANNELS.setMaterialGroup`），白名单自动随 `Object.values` 收录；preload `files.setMaterialGroup`。

## 3. 启发式规则（D75，冻结顺序、首中即停）

纯函数 `lessonMaterialGroupRole(file, context)`（新模块 `src/renderer/lesson-material-groups.ts`；context 含课次 title/lessonLabel/periodTitle、本课全部文件、md 正文快照）：

| 序 | 规则 | 归组 |
|---|---|---|
| 0 | 结构性索引壳（既有 `isStructuralLessonIndexFile`，含裸"第X课/讲"、阶段/季节名、总课程大纲） | 不进任何组（维持既有隐藏，分组前已过滤） |
| 1 | D46 讲义命名（版本链/学生版/编辑版，复用 `isLessonLectureFile`） | lecture |
| 2 | 文件名含 `习题\|作业\|题目\|答案\|真题\|练习` | exercise |
| 3 | 文件名含 `试卷\|卷子\|期中\|期末\|一模\|二模\|月考\|复习\|错题\|专项\|填选\|选填` | exam |
| 4 | 文件名含 `讲义\|精讲\|补充\|例题\|教师版\|学生版` | lecture（产品负责人裁决：补充讲义 = 讲义+习题一体系统 → 讲义） |
| 5 | 文件名主干与课次 title 互相包含（归一化后 ≥2 字符有效段） | lecture（课次标题即讲义主题，如 `相似三角形模型.md` ↔ 课次"相似三角形模型"） |
| 6 | md 正文引用了本课非图片 managed 文件（薄壳外链容器，复用树构建既有 `extractResourceReferences`；引用名匹配到非 text/markdown、非 image 文件） | lecture |
| 7 | 兜底 | misc |

- 内嵌图片（image/*）不进任何组：维持既有"按引用嵌套在所属 md 下"机制（`buildLessonMaterialTree` 零变化）；
- 规则 2/3 先于 4/5：`AMC8 余数 - 作业.md`（含课次标题且含"作业"）→ exercise；
- 实测校验（staging 902 文件命名全量回放，见 §5 验收）：K字壳 md（精讲）与 K字 docx（学生讲义）→ lecture；`习题.md`/`-作业.md`/`真题-答案` → exercise；`期中复习`/`试卷.pdf`/`选填专项` → exam；`数论补充材料`/`盐水浓度补充材料`/`例题`/`教师版` → lecture；`英语词汇`/`课本定义／定理`/`未命名` → misc；
- 规则识别错的由 D76 手动改组兜底，不追求启发式完美。

## 4. UI（D76）

### 4.1 课件区四组树

- `LessonMaterialReader` grouped 模式从两组改四组，组序：📘 讲义 → ✏️ 习题与作业 → 📄 试卷与复习 → 📎 其他资料；空组显示组空态文案（讲义组空态保留现有引导文案）；
- 讲义组内部维持 D46 语义零变化：当前版徽标（`currentLectureId`）、版本链分类（`classifyLessonCoursewareFiles`）、"设为讲义底稿"入口可见性（`isLessonLectureFile`）全部不动；
- 分组树仍按 `buildLessonMaterialTree` 构建（嵌套引用不变），四组各持自己的节点子集；
- 课程页行动卡 chips（V19-C）：讲义 N = lecture 组计数、材料 N = 其余三组之和——`splitLessonFilesByRole` 保留签名、内部改为委托新分组函数（语义演进：外部导入讲义现计入讲义侧，钉测按 D75 演进）。

### 4.2 手动改组菜单

- 文件行尾部 ⋯ 菜单（复用 V19-B `AppMenuButton`）：「设为讲义 / 习题与作业 / 试卷与复习 / 其他资料 / ─ / 恢复自动」；当前组项置灰（`disabled`），"恢复自动"仅在该文件有手动覆盖（role 非 NULL）时可用；
- 可改组白名单：本课挂课文件 − 版本链/编辑版命名文件（`isLessonLectureFile` 为 true 者不出菜单——D46 冻结语义，讲义身份不可移出）；历史版本行不出菜单；只读课次（readOnly）不出菜单；管理态（manageMode）不出菜单；
- 写入走 `files.setMaterialGroup({ fileId, group })`，成功后补发既有 `contentChanged` 广播（V110-A/D61 同先例——非内容变化但需 overview 一致刷新），section 既有 `onContentChanged → reload` 链自动刷新四组与行动卡计数；
- 失败走既有 error 条。

## 5. Main 服务与 IPC（D77）

- `ManagedFileService.setLessonMaterialGroup(fileId, group | null): SetLessonMaterialGroupResult`：
  - `requireActiveFile`；反查 `lesson_files`（`SELECT lesson_id FROM lesson_files WHERE file_id = ? ORDER BY created_at, lesson_id` 取首条，与 `setLessonFileRole` 同模式；无挂课 → `FILE_NOT_LINKED`）；
  - `UPDATE lesson_files SET role = ? WHERE file_id = ? AND lesson_id = ?`；
  - 返回 `{ file, group }`；
- IPC case：校验 → service → `notifyContentChanged({ fileId, contentChanged: true, file })`（复用既有事件，非新通道）→ 响应守卫 `isSetLessonMaterialGroupResult`；
- 零新依赖；`files` 相关既有通道零改动。
