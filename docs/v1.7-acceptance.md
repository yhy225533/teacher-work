## 安全边界复核（V1.7 重点）

- `files:write-version` 只接受 active `text/markdown` 且挂接课次的 managed 文件；临时文件 + 原子重命名，绝不 UPDATE 目标行；外部根目录资料无编辑入口（只读浏览不受影响）。
- manual_edit note 仅作来源标注（无 student_id、draft_status NULL），不参与 AI note 语义；标注失败静默不阻塞保存。
- 题库快照只读（QuestionBankDraftPort：getSummary/search/getQuestion）；候选全文只进 AI 上下文与 note body，metadata 只留 plan/数量/ID 审计。
- 候选块整块计入 maxChars=30,000 预算（D25 基线优先分配），超预算按序截减并在确认弹窗列明。
- Renderer 不直接访问 SQLite/Node/文件系统/秘密；编辑器内容经 write-version IPC 走 Main 服务；AI 产物与人工编辑产物绝不覆盖老师原资料。

## 真实 DeepSeek 自测清单（产品负责人执行，费用预估 ≤ ¥3）

1. **人工编辑器**：任一课次打开 md 课件 → “✎ 编辑” → 工具栏插入行内公式 `$…$` 与块级公式 → LaTeX 速查点选 → 插入本课图片 → 保存为新版本：旧版保留在历史版本、历史版本区出现“✎ 人工编辑：…”标注、原件未动；刷新重进出现热草稿恢复提示。
2. **AI 二改放宽**：导入一份外部 md 讲义 → 单文件修改（选外部 md）→ 方案 → 确认生成 → 发布：产物为 `原名 · 第 N 版.md`。
3. **题库选题 + 双版**：题库页导入 .tqbank → 备课参考区开“参考题库（AI 自动选题）”（目标 5 题 + 学生版开关）→ 生成修改方案：过目卡显示 AI 检索计划与候选列表 → 剔除一两道 + “调整后重新选题”（如“再难一点”）→ 确认生成（思考秒表 + 逐字上屏照常）→ 教师版题目确出自题库（对照题库页，含 `[选自题库：tag/难度]` 标注与文末“答案与解析”区块）→ 修改记录并列教师版/学生版徽标 → 学生版无答案无标注、公式正常渲染 → 各自发布：`讲义 · 第 1 版.md` 与 `讲义 · 第 1 版 · 学生版.md`。
4. **回归抽查**：不带题库开关的既有生成流一次（行为与 V1.6 一致）。
