# V1.7.3 · MD 编辑器公式输入与布局改版实施方案

> 面向实施代理的完整文字规格。视觉基准是 `tmp/mockups/md-editor-formula-redesign.html`（可交互静态稿，含生产同机制的演示引擎，本地不入库）；本文给出全部交互规则、数据表与文案，实施时不依赖图片。
> 产品负责人于 2026-09-04/05 会话中确认："md 文件想要编辑的话，这个界面实在太不方便了……牵扯到公式输入，这一部分需要大改"，调研思源笔记后逐屏确认五组场景，2026-09-05 拍板"布局选方案 A"。本方案即范围授权。

## 0. 摘要

对 `MdEditor`（`src/renderer/md-editor.tsx`，V17-C 交付）做三层增量改造，全部是 renderer 纯文本/光标层操作：

1. **数学模式**：光标进入 `$…$` / `$$…$$` 时工具栏自动切换为「符号条」，缩写（`frac`+空格 → `\frac{}{}`）自动展开、自动分式（`x` 紧跟 `/` → `\frac{x}{}`）、Tab 在空槽位间跳转并跳出公式；
2. **斜杠命令**：空行输入 `/`（或中文顿号 `、`）唤出可搜索块模板菜单，拼音缩写过滤，菜单项的值即纯文本模板（思源 `hint/extend.ts` 思路）；
3. **布局方案 A（已确认）**：可拖分栏 + ✎编辑/◫分屏/👁预览三视图（按文件记忆）+ 行比例同步滚动；预览管线加固（公式内容 LRU 缓存 + 120ms 防抖 + KaTeX 错误红色降级）。

**零新依赖、零 IPC、零 migration。** 受控 textarea + 分屏 KaTeX 的 V17-C 冻结架构（D28/D29）保持不变；保存语义（`files:write-version` 永写新文件）不动。明确否决思源式 contenteditable WYSIWYG（行内公式光标问题无解，思源作者 issue #18120 自认；且违反"不重做已冻结版本"约束）。

## 1. 背景与现状问题

现状（`src/renderer/md-editor.tsx`）：

1. 公式只有 18 项点选片段（`LATEX_SNIPPETS`，315-339 行），**矩阵、积分、极限、求导等复杂结构无任何模板**，只能手敲 LaTeX；块级公式按钮的占位文本仅为字面量"公式"；
2. 速查面板无搜索、无分类，点选后光标定位不进参数槽位，`\frac{a}{b}` 要手工删改字母；
3. 分屏 50/50 固定（`styles.css:3542-3547`），**比例不可拖**，写公式时左栏太窄、校对时右栏太小，无单屏专注模式；
4. 预览**无防抖无缓存**（textarea onChange 直接 setState，`MarkdownDocument` 每次 `parseBlocks`+KaTeX 全量重渲），长文档每敲一字全文重渲；
5. KaTeX `throwOnError:false` 失败时整段回显源码，老师看不出错在哪。

调研结论（思源/GitHub issue 第一手证据）：

- 思源**值得学的**：斜杠命令"菜单项即 Markdown 纯文本模板"+ 拼音过滤词（`hint/extend.ts`）；KaTeX 渲染 try/catch 错误红色降级（`mathRender.ts`）。
- 思源**明确不学的**：自研 contenteditable 块编辑器（Protyle + Lute WASM，数万行维护量；作者自认行内公式光标问题"无法解决" #18120，源码大量零宽字符补丁）；思源还官方拒绝了公式 snippet 补全（#576）。
- 公式输入效率最佳实践在 **Obsidian LaTeX Suite**：缩写自动展开、auto-fraction、Tab 跳槽位/跳出括号（tabout）——全部是纯文本层技术，与受控 textarea 完全兼容（其"snippet 可执行脚本"能力出于安全不做，只取数据表形态）。
- 渲染性能/容错平价实践在 **MarkText**：公式按内容缓存（改一字只重渲一个公式）、渲染失败显式错误。

## 2. 决策记录（实施 V173-A 时追加到 `implementation-tasks/V1_7_DECISIONS.md`）

**D36 · 数学模式与斜杠命令（V1.7.3 核心）**
- 数学模式侦测：光标前 `$` 计数奇偶（`$$` 视作两个 `$`），O(1) 无状态；仅在数学模式内激活缩写展开与自动分式，正文模式零干扰。
- 缩写表 `MATH_SNIPPETS`（纯数据，§5.1）按"最长触发词优先"匹配光标前文本，触发键 = **空格**（LaTeX Suite 默认，连续输入不中断）；命中则消费空格（preventDefault）并替换，光标落第一个空 `{}` 槽位内。
- 自动分式：数学模式内按 `/` 且光标前是原子（`\w+` 或 `{…}` 组）→ 立即替换为 `\frac{原子}{}`，光标留分母；前面无原子（如紧跟运算符）则正常输入 `/`。
- Tab 槽位跳转（仅编辑器内，数学模式或其后 200ms 内）：优先跳进/跳过下一个空 `{}`；无空槽位则跳过最近 `}`；都没有则跳出最近的 `$`（tabout）。不改变 textarea 焦点行为。
- 斜杠命令：空行（trim 后为空）输入 `/` 或 `、` 触发；菜单项 = 名称 + 过滤词数组（中文/英文/拼音缩写）+ 纯文本模板（含 `\u0000` 光标占位符）；↑↓ 选择、Enter/点击插入（占位符处为光标，其后空 `{}` 优先槽位）、Esc 关闭、blur 关闭；中文输入法 `compositionend` 之后才触发过滤。
- 快捷键：`Ctrl+M` 插入块级 `$$`（光标落中间）、`Ctrl+Shift+M` 行内 `$…$`（选中文字包裹）。与现有工具栏按钮、斜杠菜单共用同一插入函数。

**D37 · 布局方案 A 与预览管线（产品负责人 2026-09-05 拍板）**
- 三视图分段控件：✎ 编辑（单栏 textarea）/ ◫ 分屏 / 👁 预览（单栏只读渲染），默认分屏；按 fileId 记忆（localStorage，`md-editor-view:{fileId}`），非法值回退分屏。
- 分屏可拖分隔条：受控 `splitRatio` state（0.25–0.80，步进 0.01），pointer 事件拖动，记忆同上（`md-editor-split:{fileId}`）；单视图模式下隐藏分隔条。
- 同步滚动：**行比例近似版**——编辑侧滚动时 `editScrollTop / (editScrollHeight - clientHeight)` × 预览侧可滚动高度定位预览；仅编辑→预览单向（预览侧滚动不反向拉动，避免抢滚动）；拖动分隔条或切视图时不触发。块锚点版留作后续增量（不在本版本）。
- 预览管线：`MarkdownDocument` 外层加 120ms 防抖；`MathSpan` 渲染加模块级 `Map<string,string>` LRU 缓存（键 = displayMode+公式串，上限 300，命中即复用 HTML）；KaTeX 渲染 try/catch，失败显示红色错误消息（`katex error: <message>`）+ 原串 `title` 悬停，**代替**现有整段回源码降级。
- 沉浸模式（后期，不进本版本）：编辑器铺满窗口、左侧栏整体隐藏（一键收起、Esc 恢复）。本版本实现约束：编辑器布局不写死依赖左侧栏宽度存在，为沉浸模式留接口。

**D38 · V1.7.3 非目标**
- 不引入 CodeMirror/Monaco/ProseMirror/任何编辑器依赖；不做编辑区内嵌 WYSIWYG 或 conceal；
- 不做 snippet 可执行脚本（LaTeX Suite 的 JS snippet 有安全风险，只取纯数据表）；
- 不做 KaTeX 宏配置（思源 `katexMacros`，候选后续版本）；不做块锚点同步滚动、沉浸模式（候选后续增量）；
- 不做公式悬浮预览浮窗（本方案评审时列为阶段三候选，产品负责人未要求，暂不排期——预览栏已覆盖该职责）；
- 不改保存语义/版本链/IPC/migration；不改 AI 修改、备课工作台（V1.7.2 范围）任何逻辑。

## 5. 目标设计（to-be）

### 5.1 数学模式符号条与缩写表

工具栏渲染两个互斥形态（`mathMode` state，由光标位置 effect 推导）：

- **正文态**（现状工具栏，按钮微调）：加粗/斜体/标题/上下标/列表/引用/表格/分隔线 + `$x$`/`$$∑$$`/`▦插图` + 撤销重做；
- **数学态**（新，`.md-editor-math-bar`，琥珀色系）：分组符号条（见示意稿场景 1；每组 chip 标注触发缩写，点击 = 插入展开后模板并定位槽位）+ 右侧提示"缩写+空格 自动展开 · Tab 跳槽位"。

`MATH_SNIPPETS`（纯数据，触发词最长优先排序匹配）：

```
frac → \frac{}{}          sqrt → \sqrt{}            sum → \sum_{}^{}
int → \int_{}^{}          lim → \lim_{x \to }       mat → \begin{pmatrix} {} & {} \\ {} & {} \end{pmatrix}
cases → \begin{cases} {} \\ {} \end{cases}          pi → \pi                theta/alpha/Delta/beta → 希腊字母
le/ge/ne/app → \le \ge \ne \approx                  deg → ^\circ
vec/hat/bar → \vec{} \hat{} \overline{}             angle/tri → \angle \triangle
perp/par → \perp \parallel                           infty → \infty           cdot/times → \cdot \times
（保留现有 18 项速查中的几何/求和等条目，一并并入本表）
```

替换规则：数学模式内空格键 → 取光标前文本做最长触发词匹配 → 命中则 preventDefault 消费空格、`setRangeText` 替换（走 undo 栈）、光标落第一个 `{}` 内；未命中正常输入空格。**英文单词误触防护**：触发词表内置于数学模式内才激活（`mathMode` 才匹配），正文模式零拦截。

### 5.2 斜杠命令菜单

`SLASH_ITEMS`（示意稿演示区同款机制，含 `\u0000` 光标占位符）：

| 名称 | 过滤词 | 插入模板 |
|---|---|---|
| 块级公式 | gs / sxgsk / gongshi / 公式 | `$$\n␚\n$$` |
| 行内公式 | hjgs / inline / 行内 | `$␚$` |
| 方程组 cases | fzc / cases / 方程组 | `$$\begin{cases}\n␚ \\\\<br>\n\end{cases}\n$$` |
| 3×3 矩阵 | jz / matrix / 矩阵 | pmatrix 模板（␚ 在首格） |
| 表格 3×2 | bg / table / 表格 | 三行表格模板 |
| 分隔线 / 引用 / 一级标题 / 有序/无序列表 | fgx/hr、qy/yy、bt/h1、yxlb/ol、wxlb/ul | 对应前缀模板 |

␚ = `\u0000` 光标占位符，插入时剥除并把光标落在该处；其后有 `{}` 时优先槽位。

菜单容器 `absolute` 定位于编辑器容器内，按光标行估算偏移（与示意稿同法），超出可视高度上翻；键盘 ↑↓/Enter/Esc 全支持；过滤词 `startsWith` 匹配（词数组 = 拼音缩写 + 中文名 + 英文名）。

### 5.3 三视图与可拖分栏

- 容器改受控结构：`md-editor-view-mode`（edit / split / preview）+ `splitRatio`；
- `edit`：仅 textarea 全宽；`preview`：仅 `MarkdownDocument` 全宽（只读）；`split`：grid `splitRatio × (1-splitRatio)` + 中间 6px 拖动条（`pointerdown/move/up`，col-resize 光标，拖动中禁 textarea 捕获避免选中文本）；
- 同步滚动：`onScroll` 单向联动（比例公式见 D37）；切换视图/拖动分隔条期间挂 `syncPaused` 标志；
- 每 fileId 记忆视图与比例（localStorage 两键，读取容错回退默认）。

### 5.4 预览管线加固

- `MathSpan`：模块级 `const mathHtmlCache = new Map<string, string>()`，键 = `(display ? 'D' : 'I') + src`，LRU 300（命中重插队尾，超限删队首）；try/catch 包 `katex.renderToString`（`throwOnError: true`），失败输出 `<span class="math-error" title="{原串}">⚠ {e.message}</span>`（`.math-error` 红底样式）；
- `MdEditor` 预览渲染改 120ms 防抖（body state → debouncedPreview state；保存、恢复草稿、卸载时立即同步）；
- 防抖不影响保存（保存始终用 body）与热保存（250ms 独立）。

## 6. 交互与状态规则

1. `mathMode` 推导：selectionchange（编辑器 focus 时）→ 光标前 `$` 计数奇偶；编辑器失焦保持最后值（工具栏点击后 refocus 由 `insertTemplate` 的 rAF 处理沿用）。
2. 缩写展开、自动分式、斜杠插入、符号条点击**全部走 `pushUndo`**；展开后光标定位用 rAF（沿用 `insertTemplate` 模式）。
3. 斜杠菜单打开时输入过滤、↑↓ 移动选中、Enter 插入、Esc 关闭；菜单打开期间缩写引擎不拦截空格（菜单优先）。
4. `Ctrl+M` / `Ctrl+Shift+M` 在编辑器 keydown 全局处理（仅编辑器 focus 时），不动其它分区快捷键。
5. 三视图切换保留 undo/redo 栈与热草稿（视图是纯展示 state，不重置 body）。
6. 预览侧滚动不反向同步（单向）；用户在预览侧滚动后 800ms 内忽略编辑侧同步（防抢滚动抖动）。

## 11. 风险与回退

- **空格拦截风险**：仅数学模式内消费空格，误触面极小；若体验反馈不佳，缩写触发键可整体切换为 Tab（数据表与引擎不变，一行常量切换——设计已隔离该开关）；
- **中文输入法**：斜杠菜单过滤挂 `compositionend` 后；缩写展开仅匹配 ASCII 触发词，输入法组合期间不拦截 keydown（`isComposing` 检查）；
- **同步滚动精度**：行比例法在表格/公式密集文档有漂移，可接受（预览校对场景非逐行对齐）；不满足再议块锚点；
- **回退**：全部改动集中在 renderer 三文件 + 测试，单链 revert 即恢复 V17-C 行为；预览缓存/防抖与编辑器改动相互独立，可单独回退。
