# V1.9 · 课件导出可打印 PDF（隐藏打印窗 + printToPDF）

产品负责人 2026-09-07 立项。背景（2026-09-06 原话）："生成课件后，希望能够直接导出一份可以打印的 PDF，因为我的最终目标是纸质版。"

当前系统的课件全部是 managed Markdown 文件（AI 发布的版本链 `课次标题 · 第 N 版.md`、学生版 `… · 学生版.md`、外部导入 md、人工编辑版 `（编辑版）.md`），预览与人工编辑均已在应用内闭环，但没有任何把课件变成纸的路径——代码库中无 printToPDF、无导出实现。老师目前的打印方式只能是"用系统应用打开 md（记事本）再打印"，公式与排版全丢。

交互/流程示意：`tmp/mockups/pdf-export-flow.html`（本地不入库）。决策 D48–D54：`implementation-tasks/V1_9_DECISIONS.md`。

## 1. 目标

对课次内的 md 课件提供一键「导出 PDF」，产物可直接打印，且**与屏幕预览所见即所得**（公式、题图、表格、标题层级一致）。零新依赖、零 migration、零 AI 费用。

## 2. 技术事实（2026-09-06 代码走读）

1. **渲染管线全部在 Renderer 进程内**：`lesson-material-reader.tsx` 的 `MarkdownDocument` 是纯组件——`body + files` → `parseBlocks` 分块 → 行内 token 正则 → KaTeX `renderToString`（同步、LRU 缓存）→ React HTML。不依赖网络、不依赖 Node。
2. **图片是纯内存 data URL**：正文图片引用 `![名](文件名)` 由 `findReferencedFile` 按 `originalName`（小写）在传入的本课文件清单中匹配，再经既有通道 `files:read-content` 返回 `kind:'image'` + `dataUrl`。只要拿到「正文 + 本课文件清单」，任何窗口都能 1:1 复现预览，不存在文件路径解析问题。
3. **公式字体随包分发**：KaTeX CSS（含 woff2 字体）随 Renderer bundle 加载，file:// 下工作正常（主窗已在用）；打印前等待 `document.fonts.ready` 即可。
4. **窗口安全先例可复用**：`windowWebPreferences`（contextIsolation/sandbox/nodeIntegration:false）+ `applyWindowNavigationGuard`（deny window.open + 导航白名单）是现成模块，第二个窗口直接复用。
5. **原生对话框注入先例**：Main 服务一律通过注入端口调用原生对话框（`chooseSourcePath`、`chooseTranscript`、`chooseBackupDestination` 等），导出保存对话框沿用同模式。
6. **载荷通道 sender 校验先例**：V16-C 已建立 `extractIpcSender` 安全收窄，可把"打印载荷"通道限制为只响应本次创建的打印窗。

结论：**隐藏打印窗复用 `MarkdownDocument` + Electron 内建 `webContents.printToPDF`** 做到零新依赖、所见即所得；在 Main 进程重写一份 md→HTML 解析器的替代方案被否决（重复实现、渲染不一致、维护双份）。

## 3. 总体方案：隐藏打印窗 + printToPDF

### 3.1 数据流（一次导出的完整时序，9 步）

1. Renderer（课件区阅读器）选中 md 文件，点「导出 PDF」→ 按钮进入"导出中…"禁用态（防重复）→ invoke `export:print-to-pdf { fileId, lessonId, headerText? }`。
2. Main `ExportService` 校验：
   - `fileId` 是 active managed 文件且 `mimeType === 'text/markdown'`；
   - `lessonId` 存在且该文件确有关联（lesson_files 挂在此课次）；
   - `headerText` 长度 ≤ 100 字符（可选显示串，缺省时页眉只显示日期）；
   - 已有导出进行中 → 拒绝并返回 `EXPORT_BUSY`。
3. Main 组装打印载荷（**不信任 Renderer 传内容**）：
   - `bodyMd`：Main 侧直接读 managed 对象正文（与 `files:read-content` 同源）；
   - `files`：该课次全部 active managed 文件清单（`ManagedFileRecord[]`，供图片按名匹配；与阅读器看到的列表一致）；
   - `meta`：`{ title, headerText, exportDate }`（title = 文件 originalName 去扩展名）。
4. Main 创建隐藏 `BrowserWindow`：复用 `windowWebPreferences` + preload + 导航守卫，`show:false`，加载 `index.html?print=1`（同一 bundle）；同一时刻只允许一个导出。
5. 打印窗启动后：`main.tsx` 检测 `?print=1` 分支渲染 `PrintDocumentView`，invoke `export:get-print-payload` 取载荷（Main 校验 sender === 本次打印窗 webContents.id）。
6. 打印窗渲染完成后进入"就绪等待"：`document.fonts.ready` + 所有 `<img>` complete（失败占位与阅读器一致，不阻断）→ invoke `export:print-ready`（同样 sender 校验，只允许出现一次）。
7. Main 收到就绪 → `webContents.printToPDF(...)` 得到 Buffer。全程 60s 总超时兜底。
8. 注入的保存对话框端口（`dialog.showSaveDialog`，默认文件名 = 原文件名 `.md`→`.pdf`）→ 用户确认后：先写同目录临时文件，成功后原子重命名为目标名（防半成品；目标被占用/失败返回稳定错误并清理）。
9. 销毁打印窗；成功后 Main 侧 `shell.showItemInFolder(savedPath)`；invoke 返回 `{ saved: true }` 或 `{ saved: false }`（对话框取消）。**响应不回传路径**（守 V11-01 "绝对路径不进 Preload 响应"）。

超时/打印窗 crash（`render-process-gone` 等）→ 销毁窗口、返回稳定错误（`EXPORT_TIMEOUT` / `EXPORT_ERROR`），不留下半成品文件。

### 3.2 产物定位

- PDF 是**导出产物**，不是教学资料：不登记 `files` 表、不进搜索索引、不触发任何文件刷新、不进备份包（备份只含 managed 对象——记入已知限制）。
- 原课件文件字节不动；外部根目录资料天然不在范围内（课件区只显示挂课 managed 文件）。

## 4. 交互与入口

- **入口唯一**：课件区阅读器头部操作行（与「✎ 编辑 / 系统打开」同排）新增「导出 PDF」，仅当选中文件为 `text/markdown` 时显示。
- 点击后按钮进入"导出中…"禁用态（防重复），完成提示"已导出：文件名.pdf"或"已取消"；失败走既有 inline-error。
- V1.8.1 讲义/材料分组落地后，入口自然主要落在「📘 本课讲义」上；本方案不依赖 V1.8.1（未分组时对任何 md 可导出）。
- 版本链任何一版（当前版/历史版）、外部导入 md、编辑版、学生版均可导出——与 D27"全部 md 可 AI 二改"同宽（导出只读，风险更低）（D48）。
- 学生文件区、素材库、外部资料页不放入口（V1.9 只做课次课件区）。
- 导出不阻塞主窗：进行中可继续浏览备课；进行中再点返回 `EXPORT_BUSY` 提示。

## 5. 版式规格（D50/D51）

打印窗专用 CSS，新文件 `print-document.css`，仅打印窗加载，主窗样式零改动。

| 项 | 规格 |
|---|---|
| 纸张 | A4 纵向；`printToPDF` 设 `pageSize:'A4'`、margins top/bottom 16mm、left/right 14mm（API 英寸值 0.63/0.55） |
| 背景 | `printBackground: false`（白底黑字，省墨） |
| 字号 | 正文约 11pt（走查后可调），标题按层级缩放；中文走系统字体栈（微软雅黑） |
| 页眉 | `displayHeaderFooter: true` + `headerTemplate`：左 = headerText（如「高馨云 · 第12讲」，Renderer 拼显示串，缺省省略），右 = 导出日期；9px 灰字 |
| 页脚 | `footerTemplate` 居中「第 X 页 / 共 Y 页」（`pageNumber`/`totalPages` class） |
| 防断裂 | `.material-math-display`、`.material-markdown-image`、`table`、`pre`、`blockquote` 设 `break-inside: avoid`；`h1–h6` 设 `break-after: avoid` |
| 图片 | `max-width: 100%`；加载失败显示与阅读器一致的占位文案（不阻断导出） |
| 首页标题块 | 不加自动标题/封面（D53） |

## 6. 新增 IPC（三条，均经产品负责人批准 D54）

| 通道 | 方向 | 载荷 | 守卫要点 |
|---|---|---|---|
| `export:print-to-pdf` | 主窗 Renderer → Main | `{ fileId, lessonId, headerText? }` → `{ saved: boolean }` | hasOnlyKeys；fileId/lessonId 非空；headerText ≤ 100 字；Main 二次校验挂课关系；并发 `EXPORT_BUSY` |
| `export:get-print-payload` | 打印窗 → Main | `null` → `{ bodyMd, files, meta }` | **sender 校验**：仅本次创建的打印窗 webContents 可调（extractIpcSender 先例）；bodyMd ≤ 200,000 字符（与 write-version 同限）；files 仅记录无正文 |
| `export:print-ready` | 打印窗 → Main | `null` → `{ accepted: true }` | 同上 sender 校验；只允许出现一次 |

图片不新增通道：打印窗复用既有 `files:read-content` 拉 dataUrl。错误码新增 `EXPORT_BUSY` / `EXPORT_TIMEOUT` / `EXPORT_ERROR`（前缀 `EXPORT_`），日志只记 fileId/阶段/错误码，正文与文件名列表不进日志。

## 8. 安全边界复核

- 打印窗与主窗同安全基线：`contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`、无菜单；复用 `applyWindowNavigationGuard`（deny window.open + 白名单导航）；`show:false` 且不干扰主窗。
- Renderer 不接触文件系统与任何路径：请求只有 fileId/lessonId/显示串；响应只有 `saved: boolean`；保存路径只存在于 Main。
- 载荷通道双向 sender 校验（只认本次打印窗），防主窗 Renderer 冒充打印窗套取其他课次文件清单。
- 写盘只发生在用户经保存对话框选定的路径；先临时文件后原子重命名，失败清理，不留半成品。
- 正文、文件清单、保存路径不进日志；结构化日志仅 fileId、阶段、错误码。
- 导出为只读流程：不动 workspace.db、不动 managed 对象、不触发索引与刷新，不需要 activityGate 暂停（与备份写路径无交集）。

## 10. 非目标与已知限制

- **非目标（D54）**：PDF 编辑/加水印、docx 导出（D26 已否决）、批量静默导出整学期课件、Office/PDF/图片文件转 PDF、云端转换服务、页眉页脚可视化编辑器、多文件合并成册（D52 候选）、封面页（D53）。
- **已知限制**：
  - 导出 PDF 不进备份包（备份只含 managed 对象），PDF 由老师自行留存；
  - Chromium 对超长表格的跨页断裂控制有限（`break-inside: avoid` 只能保证单行/单块不裂）；
  - 一次导出渲染整课图片为 data URL，超大课件（几十张大图）内存峰值上升，60s 超时兜底；
  - 页眉/页脚模板字体受 Chromium 限制（仅系统字体、内联样式），不做个性化字体；
  - PDF 内文字可选可复制（未做禁止），对教学打印无影响。

## 11. 验收要点（走查清单）

1. 版本链当前版导出：公式（行内 `$…$` 与显示 `$$…$$`、`\[…\]`）与屏幕预览一致，页脚页码正确；
2. 含本课题图的课件：图片全部出现在 PDF 对应位置，无"文件名占位"；
3. 外部导入 md（含 `\[ \]` 跨行公式）导出不丢定界符；
4. 学生版 `… · 学生版.md` 导出文件名与内容正确；
5. 取消保存对话框：应用回到可用态、无报错、无残留窗口/临时文件；
6. 目标文件被占用（先在别的程序打开同名 PDF）导出：稳定错误提示，原文件未损坏；
7. 连续两次导出（第二次在第一次完成/取消后）：均正常，无 `EXPORT_BUSY` 误报；
8. 导出期间主窗可继续浏览备课（不被卡死）。
