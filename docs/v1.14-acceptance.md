## 4. 冒烟发现并修复的真实产品缺陷（V114-C 内）

**「创建后直进编辑态」被反清（D83 违约）**：`createLectureDoc` 中 `setSelectedFileId(created.file.id)` 与 `setEditing(true)` 同批提交，而 V19-B（D57）遗留的 `useEffect(() => { setEditing(false) }, [selectedFileId])` 在选中变化后清掉编辑态——探针 `probe-edit-entry.mjs` 实证（notice/胶囊已更新但 `.md-editor` 不出现）。**修复**：`enterEditingRef` 进入编辑意图标记——`createLectureDoc` 置 ref 后再选中新文件，选中变化 effect 消费 ref 置 `editing=true`（手动切文件仍保持「退出编辑」冻结语义）。钉测同步演进（lesson-prep-context 源码钉：`enterEditingRef.current = true` → 选中 effect 消费）。V114-B 全量门禁复跑（616 tests/typecheck/lint/build）全绿后进入冒烟。
