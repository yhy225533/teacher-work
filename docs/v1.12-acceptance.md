## 4. 安全边界复核

- **Renderer 不接触路径**：预览载荷经 Main 组装（readPreview → resolveEntry 解析后读文件），响应只含 name/mimeType/sizeBytes + 内容，不含任何路径；
- **路径不逃逸**：resolveEntry 完全复用（realpath + within-root 断言 + R_OK），拒绝 `..`/绝对路径/盘符/符号链接逃逸——测试三拒绝钉测；
- **纯只读**：预览零写入（不写 files 表、不建 object、不进备份/索引、零 contentChanged 广播）；外部资料原文件保持只读红线；
- **载荷守卫**：isExternalFilePreview 在 preload 过滤（dataUrl 须 data: 前缀，伪造 http 前缀拒绝——测试钉住）；
- **12MB 上限沿用**：超限 unsupported + 「文件较大…请使用系统应用打开」（测试钉住）；
- **CSP 零改动**：docx 内嵌图改 data: URL 走既有 `img-src data:` 白名单；blob: 维持被拦（钉测：index.html 不含 blob:）；
- **零 migration、零新依赖**（依赖白名单钉测 7 依赖排序全等不变）；
- **渲染器边界不变**：PdfPreview/DocxPreview/MarkdownDocument 全静态导入（renderer-boundary 测试继续通过）。

## 8. V1.12.1 维护增量证据（预览上限 50MB + 解码钉测，D73，2026-09-10 追加）

背景：产品负责人实测反馈超限覆盖面（"12MB 以上就不能看的话，是不是有太多的看不了"）并授权按实测分析实施（"按照你说的来"）。按 V1.10.1/V1.5.3.1 先例为 V1.12 最终验收前维护增量，证据并入本文档，不单独建 pass 标签。

**实测依据（tmp/v112-bench 独立基准 + production 隔离 app，产品代码零改动期间完成）**：
- 真实资料库（`D:\初中数学\公共资料`，6622 文件）扫描：可预览类型仅 25 个超 12MB（0.4%），但集中在扫描卷合订（20-33MB，一模全套 16/14 区）与整册课本（42-54MB）——备课翻卷核心场景；docx 仅 15/5151 超限（最大 19.5MB）；
- 传输链（真实文件实测）：Main 读+base64 8-32ms、IPC 过桥 39-195ms——不构成瓶颈；
- 解码链：42MB 档 `Uint8Array.from(s, c => c.charCodeAt(0))` 回调循环 **3809ms**（GC 风暴）vs 手动预分配 for 循环 **149ms**（25 倍）；**产品实现（pdf-binary.ts）原本就是 for 循环写法**（基准脚本当时误用了回调写法作对照）——本增量将其钉住防回退 + 注释记录依据；174MB 档渲染进程挂死（基准归因回调 GC 风暴 + 超大字符串），维持不可预览；
- CSP 前置验证：`fetch('data:...')` 被 production `default-src 'self'` 拦截——**方案零 CSP 改动**；
- 渲染链（真实 41.8MB 整册课本，150 页）：点击 → 首页画完 **4.46s**、渲染端 JS 堆 104MB；RSS 全进程 +972MB（全页一次性渲染语义，**懒渲染记后续候选，本增量不动**）。

**实施（单节点 V1121-A）**：managed `MAX_PREVIEW_BYTES` 与 external `EXTERNAL_PREVIEW_LIMIT_BYTES` 双侧 12MB → 50MB；`readText`（V17-C 编辑器冻结语义）拆出 `MAX_EDITABLE_TEXT_BYTES = 12MB` 不随预览放宽；`isExternalFilePreview` dataUrl 上限 20M → 70M 字符（50MB base64 ≈ 67.1M）；pdf-binary 注释记录实测依据 + 解码钉测禁回退。

**门禁（2026-09-10）**：全量 98 files / 572 tests passed（1 skipped 既有）、typecheck、lint（1 处 regex 空格 autofix 后零错）、production build、`git diff --check` 全绿；隔离 Windows 冒烟 **20/20**（V1.12 既有 18 场景零回归 + 新增 2 场景：课次阅读器与外部资料页各选一份 13MB 合成有效 PDF，断言 binary 分支可达且无超限提示——真实渲染走 pdfjs）；进程/临时目录双复核零残留。

**走查补充**（在 §5 清单之上）：任选一份 20-50MB 扫描卷/课本（此前超限）→ 直接预览；50MB+ 文件（如 54.4MB 七下课本）→ 维持「文件较大」提示（设计上限，非 bug）。
