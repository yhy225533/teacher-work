## 4. 安全边界复核

- **Renderer 不接触路径**：预览载荷经 Main 组装（readPreview → resolveEntry 解析后读文件），响应只含 name/mimeType/sizeBytes + 内容，不含任何路径；
- **路径不逃逸**：resolveEntry 完全复用（realpath + within-root 断言 + R_OK），拒绝 `..`/绝对路径/盘符/符号链接逃逸——测试三拒绝钉测；
- **纯只读**：预览零写入（不写 files 表、不建 object、不进备份/索引、零 contentChanged 广播）；外部资料原文件保持只读红线；
- **载荷守卫**：isExternalFilePreview 在 preload 过滤（dataUrl 须 data: 前缀，伪造 http 前缀拒绝——测试钉住）；
- **12MB 上限沿用**：超限 unsupported + 「文件较大…请使用系统应用打开」（测试钉住）；
- **CSP 零改动**：docx 内嵌图改 data: URL 走既有 `img-src data:` 白名单；blob: 维持被拦（钉测：index.html 不含 blob:）；
- **零 migration、零新依赖**（依赖白名单钉测 7 依赖排序全等不变）；
- **渲染器边界不变**：PdfPreview/DocxPreview/MarkdownDocument 全静态导入（renderer-boundary 测试继续通过）。
