## 5. 安全边界复核

- Renderer 只经 `window.teacherWorkbench.feedback` 两条白名单通道；转写正文只存在于请求生命周期（错误日志仅含通道与错误码，测试断言日志不含转写文字；不写日志、不进备份、不进搜索索引、不写 files 表）；
- 转写读取只接受系统对话框选中的单个 .txt/.md（filters 白名单），UTF-8 读取 + 30000 字头截断 + truncated 标注；
- 反馈 = 既有 notes 行（noteKind manual + student_id + lesson_id + occurredOn），零 migration；生成草稿永不落库，保存永远走老师确认过的正文；手写路径完全不经 Skill 与 AI；
- `CreateNoteRequest.aiMetadata` 可选字段经 `isFeedbackNoteMetadata` 严格守卫（generatedBy='feedback-assistant' 固定值 + 字段类型 + hasOnlyKeys），既有可能载荷路径行为零变化（既有 create-note 钉测全绿）；
- AI Key 仅进 secure storage（冒烟用 fake Key + localhost endpoint）。
