# V1.7.2 · 备课工作台结构重排（AI 修改/新建备课工作区）实施方案

> 面向实施代理的完整文字规格。实施模型**不需要看任何图片**：本文给出全部 DOM 结构、CSS 值、文案与状态规则；视觉与样式基准是仓库内可直接阅读的 `tmp/mockups/prep-workspace-structure.html`（纯 HTML+CSS 静态稿，类名与本文一致或接近，以其 CSS 值为准抄写）。
> 产品负责人于 2026-09-03/04 会话中下达："左边这个 ui 绝对不行""结构肯定要重排的"，并逐项确认了新结构（左轨=修改记录、配置进主区生成器卡）。本方案即范围授权。

## 0. 摘要

把 `DraftPanel`（`src/renderer/draft-panel.tsx`）备课工作台从"左栏塞配置+记录"重排为：

- **左轨（250px）只放"修改记录"时间线**——新建/单文件/整课三种模式下结构完全一致；
- **主区顶部一张宽的"生成器"卡片**承载本次生成的全部配置，一行一类：范围行（修改对象/生成依据）、参考行（chips + 三个添加入口 + 参考题库开关）、预算行、要求区（textarea + Skill + 生成按钮）；
- **阅读成果时生成器自动收成一行摘要**（含"调整要求"按钮）；
- **题库"目标题数 / 同时生成学生版"两个参数从配置区挪到题库候选区头部**（候选本来就在主区展示，参数放候选旁边）。

**只动展示层。** 生成/修改/题库/预算/发布的全部状态机、handler、IPC、Main 逻辑零改动；零新依赖；无 migration；无新 IPC。

## 1. 背景与现状问题

现状（`draft-panel.tsx:1043-1145`）：左栏 `aside.prep-ref-panel`（grid 250px 里实际限宽 220–260px，`styles.css:2994-2999`）纵向塞了 5 组内容：修改对象单选列表、补充参考勾选列表、参考题库开关（含目标题数/学生版）、两个大添加按钮、修改记录列表。问题：

1. "参考题库（AI 自动选题）"13px 文案在窄栏换行成三行、checkbox 悬空（`styles.css:3363-3415`）；
2. 每个小节用三行式 `card-heading`（kicker+h2+计数），窄栏里节头吃掉大半屏；
3. "从外部资料添加/从素材库添加"是整栏宽堆叠大按钮，视觉权重错位；
4. 修改对象列表常驻展开（单文件模式默认已自动选中，`draft-panel.tsx:275-300`），纯占高度；
5. 预算提示是 10px 三行绕口令；右侧 `prep-scope-strip`（`draft-panel.tsx:1147-1152`）与左栏修改对象信息重复展示；
6. 左栏 sticky + 内部 overflow 与页面滚动形成双滚动条。

### 5.3 三模式差异矩阵（生成器内部）

| 区块 | 新建备课（new） | 修改当前文件（single） | 整课重做（lesson） |

| 范围行 label | 生成依据 | 修改对象 | 修改范围 |
| 范围行内容 | 已选 chips 或冷启动大入口卡（§5.6） | 目标文件卡 + [更换]（§5.5） | 绿色自动徽标（§5.5） |

## 6. 交互与状态规则

**新增 state（仅 2 个）+ 复用：**

```ts
const [targetPickerOpen, setTargetPickerOpen] = useState(false)  // 修改对象“更换”展开
const [refPickerOpen, setRefPickerOpen] = useState(false)        // 本课资料候选勾选列表展开
const [generatorOpen, setGeneratorOpen] = useState(true)         // 生成器展开/收起
```

**规则（全部为确定性规则）：**

1. `selectTargetFile(fileId)`：现有逻辑执行后追加 `setTargetPickerOpen(false)`（选中即收起）。
2. `changePrepMode`：追加 `setTargetPickerOpen(false); setRefPickerOpen(false); setGeneratorOpen(true)`。
3. 外层 context 重置 effect（`draft-panel.tsx:234-273`）末尾追加三个 set 的重置（false / false / true）。
4. 新增 effect：`useEffect(() => { setGeneratorOpen(selectedNoteId === null) }, [selectedNoteId])` —— 选中任意节点（含生成完成、恢复最近工作副本、点左轨记录）自动收起；无选中节点时强制展开。用户点"调整要求"展开后，只有 selectedNoteId 再次变化才会重新收起。
5. `abandonImprove`、`startImprovePlan` 抛错取消时追加 `setGeneratorOpen(true)`（保证可改要求重试）。
6. 禁用矩阵不变：所有按钮/开关的 `disabled` 条件沿用现有 `busyAction !== '' || improveBusy` 组合；chips 的 ✕ 与 `prep-add-mini`、`prep-add-card` 同样受 `busyAction !== ''` 禁用（picker 往返由既有页面负责）。
7. picker 展开列表渲染在对应 `prep-gen-field` 之下（同一 `prep-gen-row` 内、field 之后），不弹层。
