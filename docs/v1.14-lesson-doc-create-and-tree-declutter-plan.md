# V1.14 课件区新建讲义 + 树降噪 · 设计基准

- 日期：2026-09-14
- 状态：已冻结（产品负责人 2026-09-14 拍板：新建入口 = ⋯ 菜单 + 讲义组头 ＋ 双入口；新建形态 = 版本链讲义；空组一行化；附加降噪三项全做——树头去重 / 隐藏"外部资料"徽标 / 启发式补词）。同日复审修订（D86/D87）：版本链按基名分链显示、历史版本收 ⋯ 按需唤出、工具行重排（沉浸阅读降为行尾图标）。原 D82–D85 语义零变化，D86 在 D82 的分类消费侧补齐多链支持。
- 背景：产品负责人实测——①课件区没有任何"从零创建"入口（⋯ 菜单全部是加工已有文件的动作），手写讲义这条路断裂；②四组固定展示下空组占块 + 长引导文案 + 重复树头 + 全员"外部资料"徽标，结构性噪音超过内容本身。复审追加两条：③讲义组不应给老师看到一份讲义的每个版本，只显示最新版，历史按需可看；④工具行失衡——沉浸阅读（视图开关）占据第一顺位全宽按钮，而视图开关应降级。
- 决策：D82–D85（`implementation-tasks/V1_14_DECISIONS.md`）+ 修订 D86/D87（同文件）。

## 1. 新建讲义（D82/D83）

- **语义 = 版本链讲义**：创建 `名称 · 第 1 版.md`（重名自动顺延 `第 N 版`，与"设为讲义底稿"同规则），落讲义组、带"当前"徽标、可 ✎ 编辑、可 ✦修改这份走 AI——手写讲义与 AI 生成讲义同级。
- **双入口**：①工具行 ⋯ 菜单"本课"组第一位「＋ 新建讲义」；②讲义组头右侧轻量「＋」。readOnly 均不渲染。无 md 课次的工具行不渲染 ⋯（既有 V19-B 分支结构），该场景由组头「＋」与整课空态引导承担新建入口。
- **流程**：点击 → 应用内 `requestText` 输入框（默认名 = 课次标题）→ `files:create-lesson-doc {lessonId, name}` → 创建后选中新文件并**直接进入编辑态**开写。名称与既有链同基名 = 延续该链下一版；新基名 = 独立新链（D86 后并立显示，见 §2）。
- **Main**：`ManagedFileService.createLessonDoc(lessonId, name)`——requireActiveLesson → 名称 trim/去控制字符/≤80 字（空或超长 → `FILE_SOURCE_INVALID`）→ `nextLectureBaseVersionNumber` 取版本号 → `createTextObjectAndRegister("# ${base}\n", "base · 第 N 版.md", lesson link)`（复用原子写入与既有登记管线）→ 返回 `{ file, version }`（复用 `WriteFileVersionResult` 守卫）；enqueueIndex + 补发 contentChanged。
- 零新依赖、零 migration；新 IPC 仅一条 `files:create-lesson-doc`。

## 2. 版本链分链显示 + 历史按需（D86）

**缺陷（V1.13.2 即存在，D82 使其主流化）**：`classifyLessonCoursewareFiles` 把课次下所有 ` · 第 N 版.md` 视为一条链、只取全课版本号最高者为"当前"，其余全部入历史——而 Main 侧版本号按基名独立计数。第二条链出现时（设为讲义底稿起不同基名 / 新建讲义起自定义名），其链头会被误判成"历史版本"藏进底部折叠块，且"创建后直进编辑"因新文件不在 currentMaterials 而选不中。

1. **按基名分链**：classify 改为按基名（`基名 · 第 N 版` 去版本后缀；` · 学生版` 不匹配版本链 pattern，维持现状随材料显示）聚合——每条链的最高版进 currentMaterials，其余进 history（按链分组）。消费者同步受益：draft-panel 的修改候选/引用候选不再漏第二条链的讲义。
2. **链头行显示基名**：讲义组树行只显示基名（如「二次根式」），不带「 · 第 N 版」后缀——链头即最新版，版本号属于历史细节；树行去后缀与 `displayFileName` 的扩展去后缀规则一致，完整版本名保留在历史块与胶囊。
3. **主讲义 = 最近保存的链**：`currentVersion` 语义从"全课版本号最高"改为"各链头中 createdAt 最新"（保存新版本会创建新文件记录，链头创建时间即链的最近保存时间）；自动选中与「当前」徽标跟随主讲义链头；hover ✕ 白名单保护扩展到**所有链头**（误移除正文是高后悔动作，移除仍可走 ⋯ 红区）。
4. **历史版本按需唤出**：底部常驻「🕘 历史版本（N）」details 行退役；⋯ 菜单「本文件」组在选中链头且链内旧版 > 0 时显示「🕘 历史版本（N）」，点击后展开既有 details 形态（标题按链标注「『基名』历史版本」，默认展开）；条目内 系统打开/移除 语义不变。

## 3. 工具行重排（D87）

- **顺序**：`✦ 修改这份`｜`✎ 编辑`｜`⬇ 导出 PDF`｜`⛶ 沉浸阅读（图标）`｜`⋯`——恢复 v1.9/D57 冻结方案原序（实现时沉浸阅读因跨状态渲染被提到首位，属偏差）。
- **沉浸阅读降级**：全宽文字按钮 → 38px 图标按钮（`.toolbar-icon-btn`，title/aria-label 完整语义；激活态高亮；进入后变"退出沉浸阅读"）。不收进 ⋯：课堂细读长文是真实场景，降体量不降可达性。后续候选：挪到正文区右上角与编辑器视图条（✎/◫/👁）同体系。
- **依据（频次审计，产品负责人 2026-09-14 确认）**：工具行放"作用于当前选中文件的内容动作"（编辑/AI 修改/导出——高频、有产物）；视图开关降级；课级动作（新建讲义）不入工具行大按钮——其可见入口由讲义组头「＋」承担，⋯ 为第二入口；低频/兜底/破坏性留 ⋯（分组不变：本课 / 本文件 / 红区）。
- readOnly 维持 `⬇ 导出 PDF` + ⛶ + ⋯；无 md 分支维持 引导 + AI 主键 + ⛶（不渲染 ⋯）。

## 4. 树降噪（D84）

1. **空组一行化**：空组标题显示"📘 本课讲义 · 暂无"，删除各组空态文案；引导合并进整课 0 文件的空态一句（"本课次还没有资料——可从外部资料/素材库导入，或点讲义组 ＋ 新建讲义、用 AI 生成第一版课件。"）。
2. **树头去重**：树头不再渲染课次标题（工具行已有），只留 "N 项 [管理]"。
3. **徽标降噪**："外部资料"是默认来源、无信息量——来源徽标只显示"素材库"（工作台产物本就不显示）；新助手 `lessonFileBadgeLabel`（外部资料 → null）。
4. **启发式补词**：exercise 词表追加 `特训|精练|全解全析|分层|\d{1,3}题`——"二次根式80题全题型"类落习题与作业（误判可手动改组，V1.13 通道）。
