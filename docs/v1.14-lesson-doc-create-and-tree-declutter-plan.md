# V1.14 课件区新建讲义 + 树降噪 · 设计基准

- 日期：2026-09-14
- 状态：已冻结（产品负责人 2026-09-14 拍板：新建入口 = ⋯ 菜单 + 讲义组头 ＋ 双入口；新建形态 = 版本链讲义；空组一行化；附加降噪三项全做——树头去重 / 隐藏"外部资料"徽标 / 启发式补词）。
- 背景：产品负责人实测——①课件区没有任何"从零创建"入口（⋯ 菜单全部是加工已有文件的动作），手写讲义这条路断裂；②四组固定展示下空组占块 + 长引导文案 + 重复树头 + 全员"外部资料"徽标，结构性噪音超过内容本身。
- 决策：D82–D85（`implementation-tasks/V1_14_DECISIONS.md`）。

## 1. 新建讲义（D82/D83）

- **语义 = 版本链讲义**：创建 `名称 · 第 1 版.md`（重名自动顺延 `第 N 版`，与"设为讲义底稿"同规则），落讲义组、带"当前"徽标、可 ✎ 编辑、可 ✦修改这份走 AI——手写讲义与 AI 生成讲义同级。
- **双入口**：①工具行 ⋯ 菜单"本课"组第一位「＋ 新建讲义」；②讲义组头右侧轻量「＋」。readOnly 均不渲染。
- **流程**：点击 → 应用内 `requestText` 输入框（默认名 = 课次标题）→ `files:create-lesson-doc {lessonId, name}` → 创建后选中新文件并**直接进入编辑态**开写。
- **Main**：`ManagedFileService.createLessonDoc(lessonId, name)`——requireActiveLesson → 名称 trim/去控制字符/≤80 字（空或超长 → `FILE_SOURCE_INVALID`）→ `nextLectureBaseVersionNumber` 取版本号 → `createTextObjectAndRegister("# ${base}\n", "base · 第 N 版.md", lesson link)`（复用原子写入与既有登记管线）→ 返回 `{ file, version }`（复用 `WriteFileVersionResult` 守卫）；enqueueIndex + 补发 contentChanged。
- 零新依赖、零 migration；新 IPC 仅一条 `files:create-lesson-doc`。

## 2. 树降噪（D84）

1. **空组一行化**：空组标题显示"📘 本课讲义 · 暂无"，删除各组空态文案；引导合并进整课 0 文件的空态一句（"本课次还没有资料——可从外部资料/素材库导入，或点 ⋯ 新建讲义、用 AI 生成第一版课件。"）。
2. **树头去重**：树头不再渲染课次标题（工具行已有），只留 "N 项 [管理]"。
3. **徽标降噪**："外部资料"是默认来源、无信息量——来源徽标只显示"素材库"（工作台产物本就不显示）；新助手 `lessonFileBadgeLabel`（外部资料 → null）。
4. **启发式补词**：exercise 词表追加 `特训|精练|全解全析|分层|\d{1,3}题`——"二次根式80题全题型"类落习题与作业（误判可手动改组，V1.13 通道）。
